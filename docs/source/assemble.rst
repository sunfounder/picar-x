Assemble the PiCar-X
==========================================

Bevor Sie mit der Montage des PiCar-X beginnen, vergewissern Sie sich bitte, dass alle Teile und Komponenten enthalten sind. Sollten Komponenten fehlen oder beschädigt sein, kontaktieren Sie SunFounder umgehend unter service@sunfounder.com, damit das Problem schnell gelöst werden kann.

Dieses Video führt Sie Schritt für Schritt durch die Montage Ihres Roboters von Grund auf.

.. note::

    Die Montageschritte im Video können geringfügig von den gedruckten Anleitungen abweichen. Bitte halten Sie sich vorrangig an die gedruckte Anleitung. Falls einzelne Schritte unklar sind, können Sie zur weiteren Klärung das Video heranziehen.

In diesem Tutorial lernen Sie:

* **Preparation**: Wir stellen Ihnen alle benötigten Werkzeuge und Teile vor, damit Sie vor dem Start vollständig ausgerüstet sind.

* **Assembly Steps**: Wir demonstrieren jeden Montageschritt in systematischer Reihenfolge.

* **Tips and Considerations**: Während des gesamten Prozesses geben wir wichtige Hinweise und Tricks, damit Sie typische Fehler vermeiden und Ihr Fahrzeug reibungslos läuft.

* **Zeroing a Servo**: Bevor jedes Servo befestigt wird, muss es zunächst genullt werden. Die Schritte zum Nullabgleich sind: zuerst das Raspberry-Pi-OS installieren, dann die erforderlichen Module installieren und anschließend ein Skript ausführen (den Winkel aller PWM-Pins auf 0 setzen). Danach das Servokabel einstecken, um das Servo zu nullen.
