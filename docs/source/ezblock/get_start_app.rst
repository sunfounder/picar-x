安装与配置 EzBlock Studio
=========================================

机器人组装完成后，您需要进行一些基本操作。

* :ref:`ezblock:install_ezblock_app_latest`：在您的设备上下载并安装 EzBlock Studio，或使用 Web 版本。

.. note::

    如果您使用的是 Raspberry Pi 5，请下载 Beta 版本。
    使用过程中有任何疑问或问题？请随时联系我们。

    .. image:: img/ezblock_beta_version.png
       :width: 800

* :ref:`ezblock:connect_product_ezblock_latest`：使用前配置 Wi-Fi、蓝牙并进行校准。
* :ref:`ezblock:open_run_latest`：直接查看或运行相关示例。

.. note::

    连接 PiCar-X 后，会有一个校准步骤。这是因为安装过程中可能存在偏差，或舵机本身存在限制，导致一些舵机角度略微倾斜，您可以在此步骤中进行校准。

    但如果您认为安装完美，无需校准，也可以跳过此步骤。
